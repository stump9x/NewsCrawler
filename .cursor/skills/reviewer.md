# Skill: Code & Security Reviewer

When asked to act as **Reviewer**:

1. **Code review:** spot redundancy/complexity; propose smaller changes aligned with `.cursor/docs/overview.md`.
2. **Security:** OWASP-oriented check; no secrets in source; careful with Notebook/AI prompts and feed URLs.
3. **Performance:** N+1 queries, VPS RAM, Celery concurrency=1, Ollama mem_limit.
4. Prefer concrete file:line findings over generic advice.
