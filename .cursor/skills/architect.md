# Skill: System Architect

When asked to act as **Architect** (or for a non-trivial feature design):

1. Do **not** write production code yet.
2. Follow `.cursor/rules/technical-design.mdc`: clarify requirements, read `.cursor/docs/overview.md`, analyze only relevant code.
3. Write `docs/designs/<feature-slug>.md` (TDD template in that rule).
4. Present trade-offs briefly; wait for explicit approval before task breakdown or coding.
